프로젝트 소개
---

이름: skala-vue (SKALA 교육과정 Vue 실습 프로젝트)
브랜치: develop (원격과 동기화됨, working tree clean)
실행: npm run dev (Vite, 기본 포트 5173)
API 키: .env 의 VITE_WEATHER_API_KEY (OpenWeatherMap 무료 플랜)

기술 스택
- Vue 3 (script setup, Composition API)
- Vite 8
- Pinia (상태관리)
- Vue Router 5
- Element Plus (UI 컴포넌트, main.js에서 전역 등록됨 -> 컴포넌트에서 import 없이 <el-xxx> 바로 사용 가능)
- Axios (OpenWeatherMap REST 호출)
- Three.js (3D 지구본, EarthSection.vue에서만 사용)
- 폰트: Google Fonts "Jua" (전역 적용, index.html + main.css)

앱이 뭔지 한 줄 요약
"날씨 대시보드" 위에 "지구 샌드위치 시뮬레이터"라는 미니게임을 얹은 프로젝트.
지구 샌드위치(Earth Sandwich) 밈: 지구를 사이에 두고 정확히 대척점(반대편)에 있는
두 사람이 각자 빵 한 조각씩 놓으면 지구를 통째로 샌드위치처럼 만들 수 있다는 아이디어.
이 프로젝트에서는:
  1. 사용자가 도시를 하나 선택(검색 또는 추천 카드 클릭, 또는 3D 지구본을 돌려서 직접 지정)
  2. 그 도시의 위도/경도로 정확한 대척점(반대편 지점) 좌표를 계산
  3. 두 지점 모두 실시간 날씨(OpenWeatherMap)를 조회
  4. 온도/습도 기준으로 "식빵 상태"(바삭/눅눅/꽁꽁얼음/완벽)를 판정
  5. 양쪽 다 "완벽"이면 게임 승리("N번만에 승리!")

디자인 컨셉: 전체 UI를 "빵/식빵" 테마로 통일

9. Three.js 3D 지구본 (EarthSection.vue) - 단계별로 발전시킴
   a. three, three/addons/controls/OrbitControls 설치 후 기본 구체 + 조명 + OrbitControls로 시작
   b. earth_day_4096.jpg (사용자 제공 equirectangular 세계지도 텍스처) 적용
   c. 빵 오브젝트 추가: 처음엔 whiteBread500.png 텍스처 썼다가, 최종적으로 이미지 없이
      THREE.Shape(모서리 4곳 둥근 사각형) + ExtrudeGeometry로 두께 있는 라운드 육면체를
      코드로 직접 생성. ExtrudeGeometry material group은 0=앞뒷면(내용물색),
      1=옆면(테두리색) 순서라 헷갈리기 쉬움 (three.js 소스 확인해서 검증함)
   d. 빵은 항상 월드 좌표 (0, 1.3, 0)에 고정 (지구의 자식이 아니라 scene에 직접 추가) ->
      지구가 돌아도 빵은 화면상 같은 자리에 고정됨. rotation.x = Math.PI/2로 눕혀서
      아래(지구 쪽)를 향하게 함
   e. 빵 -> 지구 표면(빵 위치를 정규화한 지점)까지 이어지는 점선(LineDashedMaterial),
      매 프레임 dashOffset 감소시켜서 점선이 흐르는 애니메이션. 색은 현재 '#ff0000'
      (사용자가 디버깅용으로 빨간색으로 직접 바꿔놓음, 원래는 --bread-border-color였음)
   f. 지구 자전: 처음엔 세게 자동회전 -> 나중에 아예 제거 -> 최종적으로 약하게
      (0.0008/frame) 자동회전 + 사용자가 드래그로 잡고 있는 동안은 멈추고 놓으면 재개
   g. 드래그 조작: OrbitControls 제거하고 직접 pointerdown/move/up으로 구현.
      가로 드래그 -> earth.rotation.y (경도 회전/스핀), 세로 드래그 -> earth.rotation.x
      (위도 방향 기울이기). *가로 드래그만으로는 극지방 근처 위도가 잘 안 바뀜 -
      실제 지구본처럼 세로로 기울여야 다른 위도가 위로 올라옴 (물리적으로 정상 동작, 버그 아님)
   h. 빵이 가리키는 지점의 위도/경도 계산 (getLatLonUnderBread): 고정된 월드좌표
      (0,1,0)을 earth.quaternion의 역행렬로 지구 로컬좌표로 변환한 뒤 theta/phi ->
      lat/lon 환산. 역변환 함수는 latLonToLocalDirection (표면에 빵 붙일 때 사용)
   i. 드래그를 놓는 순간(pointerup) 그 위도/경도로 OpenWeatherMap 조회 ->
      지구본 오른쪽에 WeatherCard로 결과 표시 (바다면 "바다"로 표시, 국기 없음)
   j. sandwich.log 재현: 컴포넌트 mount 시 log의 각 항목(selectedCity, oppositeCity)의
      위도/경도에 작은 빵 조각(createSurfaceBread)을 지구 표면에 배치. 이번엔 반대로
      earth.add(mesh)로 지구의 **자식**으로 붙여서 지구 자전에 같이 따라가게 함.
      -> 시도할수록(=WeatherDetailView 방문할수록) 지구가 빵으로 뒤덮이는 효과
